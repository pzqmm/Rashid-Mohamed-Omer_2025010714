## 5. How to Run the Projects
1. Clone the repository or open it in GitHub Codespaces.
2. Navigate to the desired week's folder using the terminal (e.g., `cd week_2`).
3. Compile the Java files using: `javac *.java`
4. Run the main class using: `java Main`
